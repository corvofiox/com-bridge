# v0.3.1 — 开机静默启动 + 副机等待主电脑

两个实测问题 + 三个安全加固。**建议两台机器都升级**。

## 1. 开机自启不再弹窗口（静默启动）

自启命令现在带 `--autostart`：登录后只创建托盘图标并自动拉起上次的角色，**主窗口不出现**。左键托盘图标随时能把窗口叫回来。

老机器上已登记的裸路径命令会在新版本**首次启动时自动改写**，不需要你手动关开自启开关。

## 2. 副机等待主电脑握手（不再报错退出）

两台都开机自启时，副机几乎总是先到。旧版本控制通道只试连一次，失败就 `raise RuntimeError`，界面停在"启动失败"。

现在改为常驻重试（指数退避 1→2→4→5s 封顶，默认**不设上限**）：

| | 旧 | 现在 |
|---|---|---|
| 连不上 | 报错结束 | 等待，每 10s 一行进度日志 |
| 界面 | 红色"启动失败" | `等待主电脑…(已等 Ns, 探测 M 次)` |
| 托盘 | — | 提示同步为"等待主电脑…" |
| 停止按钮 | 无效 | = **取消**，显示灰色"已取消" |

**实测**：主机延迟 2.5s 才起来 → 副机等 3.1s 后自动完成握手（版本协商 + 对时）；按停止 1.47s 退出并归类"取消"。

## 3. 穿越逃生通道：Ctrl+Alt+Esc

穿越期间本机键盘被低级钩子吞掉（含 `Win`/`Alt+Tab`/`Ctrl+Shift+Esc`）、鼠标被 SetCapture 捕获、光标隐藏——退出只剩"副机回程信号"一条路。若触发条件出错而副机还活着，用户此前**没有任何自救手段**。

现在按 `Ctrl+Alt+Esc` 立刻收回控制权（只在穿越态生效，常态按到无副作用）。`Ctrl+Alt+Del` 始终有效（SAS 不经过任何用户态钩子）。

## 4. 强制交回后的冷静期（消灭"抢控制权抖动"）

日志实证：交回后 100ms 又被同一个贴边动作抓回去，每秒一次地抢前台 + 建全屏窗 + SetCapture + 隐藏光标，全屏程序被反复打断。现在强制交回后 2s 内忽略越界判定。

## 5. 不从前台的全屏程序抢焦点

保活定时器原本每 100ms 抢一次前台且永不放弃——对全屏程序（游戏/远程桌面客户端/播放器）是灾难：它们每次想拿回焦点都被抢走，画面黑掉。现在前台是**别的进程的全屏窗口**时不抢；连续抢 3 次失败也放弃本轮。并排除 `Progman`/`WorkerW` 等外壳窗口（空桌面同样覆盖全屏，误判会让光标在空桌面上藏不住）。

## 6. 其他修复

* `KeyError: 'events_injected'`：该计数从未初始化，副机每回送一个事件就抛异常（上一版日志里 49 次）。不影响注入落位，但诊断计数恒为 0 且日志刷异常。
* 测试卫生：`tests/test_autostart.py` 会真实改写用户的 HKCU Run 自启项且不还原——跑一次全量测试就可能把你的开机自启改掉。已加快照/恢复。

## 升级说明

替换 `com-bridge-gui.exe` 后重启程序即可。**先重启两台机器再连接**，可以专门验证"副机先起、等待主机"这条路径。

测试：561 passed / 0 failed（停掉正在运行的实例后）。
